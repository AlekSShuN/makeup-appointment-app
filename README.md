# makeup-appointment-app
SPA для визажиста с системой записи клиентов

Стек:
Frontend: React, React Router, Vite, CSS Module
Back: Node.js, Express.js, MongoDB
Сборка: Vite

Установка: 
Клонировать репозиторий:
git clone https://github.com/ваш-username/makeup-appointment-app.git
cd makeup-appointment-app

Установить все зависимости: 
npm run install:all
