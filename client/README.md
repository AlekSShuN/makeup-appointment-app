## Быстрый старт

### Предварительные требования
- Node.js 16+ 
- npm 8+

### Установка и запуск

```bash
# Клонирование репозитория
git clone <your-repo-url>
cd makeup-appointment-app

# Установка всех зависимостей (клиент + сервер)
npm run install:all

# Запуск в режиме разработки
npm run dev
